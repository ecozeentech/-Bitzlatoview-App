# Store listing assets

Place final creative assets in this folder before Play Store / App Store submission.

## Required assets

### Google Play

| Asset | Spec |
|-------|------|
| App icon | 512×512 PNG |
| Feature graphic | 1024×500 PNG |
| Phone screenshots | ≥ 2 (recommend 8), show native chrome (settings / offline / splash) |
| Privacy policy URL | From the web platform |

### Apple App Store

| Asset | Spec |
|-------|------|
| App icon | 1024×1024 PNG (Xcode also needs full icon set) |
| iPhone screenshots | ≥ 3 |
| iPad screenshots | ≥ 3 |
| Privacy policy URL | Required |

## Listing copy guidance

Emphasize that Bitzlatoview Mobile is a **native client** with:

- Push notifications for trade / P2P alerts
- Biometric authentication for sensitive actions
- Native file picker & camera for KYC
- Deep linking into specific trades and orders
- Offline handling and secure session persistence

Do **not** describe the app as “just a website wrapper”.

## Risk language

Include a clear statement that trading involves risk and that no returns are guaranteed. Link to the web risk disclosure page.
