## Full description

Bitzlatoview Mobile is the official native app for the Bitzlatoview trading platform. Access spot trading, futures, P2P, copy trading, AI bots, mining, virtual cards, and more — with a secure, native mobile experience.

**Native mobile features:**
- Push notifications for trades, orders, and account alerts
- Biometric authentication for secure access
- Native file picker and camera for KYC verification
- Deep linking to specific trades and orders
- Offline detection with automatic retry
- Secure session persistence across app restarts

**Platform features (via secure WebView):**
- Spot, futures, stocks, forex, and NFT markets
- P2P trading with escrow protection
- Multi-wallet system (Primary, Trading, Investment)
- Copy trading and AI strategy marketplace
- Compliance-first design with risk disclosures

All financial operations are processed securely on Bitzlatoview servers. Trading involves risk of loss. No guaranteed returns.
