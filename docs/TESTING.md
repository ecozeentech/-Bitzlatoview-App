# User Testing Instructions

## Android – Internal Test Track

1. Admin shares the Google Play internal testing link.
2. Open the link on your Android device and tap **Join the test**.
3. Install **Bitzlatoview** from the Play Store.
4. Log in with your test account.
5. Test: login, dashboard, trading pages, deposit/withdraw, KYC upload, settings logout.
6. Report bugs via in-app support or email support@bitzlatoview.org.

## iOS – TestFlight

1. Accept the TestFlight invitation email.
2. Install **TestFlight** from the App Store if needed.
3. Open TestFlight → **Bitzlatoview** → **Install**.
4. Complete the same test flows as Android.
5. Shake device or use TestFlight feedback for bug reports.

## What to verify

- [ ] Splash screen appears on launch
- [ ] Website loads within a few seconds
- [ ] Login persists after force-quit and reopen
- [ ] Pull-to-refresh works
- [ ] Offline screen appears when airplane mode is on
- [ ] Settings → Privacy / Terms / Risk disclosure open correctly
- [ ] Logout returns to login page
- [ ] Push notification permission prompt (first launch)
- [ ] KYC file upload opens native picker (if triggered from web)

## Test accounts

Use credentials provided by your admin. Do not use production funds during beta testing.
